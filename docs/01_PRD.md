# ResolveIT product requirements

ResolveIT frames IT reports in English, Hindi and Hinglish into eleven epistemic slots, recommends responsible teams and asks at most one useful clarification. Success means measured reductions in reassignments and triage time on independently audited customer incidents, with selective routing risk within a certified bound. No absolute zero-bounce promise.

## Workspaces

| Workspace | Required user outcome |
| --- | --- |
| Intake | Persist report immediately, show evidence/frame, permit one question/skip, show human deferral and provenance |
| Review | Blind audit plus independent dual annotation, adjudicate conflicts, inspect support-aware agreement, export permitted split data |
| Bounce analysis | Validate/import CSV with explicit queue mapping, show reassignment histories and observed costs without fabricated data |
| Evaluation lab | Compare four declared baselines and shipped bundle by provenance/split/language/queue; suppress unsupported claims |
| Agent handoff/explorer | Inspect standard MCP and opt-in enterprise handoff, citations, state expiry and system flow |
| Settings/privacy | Manage queue maps, versioned costs and routing status; request authorized erasure with explicit irreversible confirmation |

## Roles and acceptance

Tenant admin manages configuration and erasure. Reviewer labels/triages within tenant. Viewer reads permitted incidents/metrics. Agent submits via scoped machine credential. Browser sessions must resolve tenant and role; server-wide demo key cannot supply production identity.

Every workspace needs keyboard operation, visible focus, readable error/empty/loading states, 320px layout, reduced-motion support and WCAG 2.1 AA evidence. Warm Obsidian, Alabaster and Signal Crimson identify hierarchy and status without relying on color alone. Charts expose accessible tables or labels.

Synthetic fixtures and LLM silver labels remain labeled on every affected view/export. Human gold requires independent annotation/adjudication provenance; agreement is calculated from actual overlapping labels. Missing metrics display unavailable with reason. Commercial zero-bounce eligibility waits 72 hours of verified observation under a versioned policy; UI explains exclusions and delayed readiness.

Out of scope until evidence supports complexity: autonomous remediation, unbounded multi-question chat, new distributed queue infrastructure and billing money movement. Building billing ledger is authorized; charging customers requires explicit commercial action.
